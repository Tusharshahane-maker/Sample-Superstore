Developed an interactive Power BI dashboard to visualize key sales and marketing KPIs for a mid-sized retail company. Integrated multiple data sources including Excel and SQL Server to create a unified data model. Used Power Query for data transformation and DAX for calculated measures and time intelligence. Designed visually appealing reports with slicers, drill-downs, and tooltips for enhanced user interaction. Enabled stakeholders to track sales trends, regional performance, product profitability, and customer acquisition metrics in real time.
Key Contributions:

Reduced manual reporting time by 50% through automation.

Improved decision-making by providing real-time insights into product and regional performance.

Ensured data accuracy and consistency across multiple datasets.
